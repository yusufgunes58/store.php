# store.php
Store Management System with PHP &amp; MySQL

# Purpose and About Project
Satış temsilcilerinin ürün ekleyebileceği, sipariş oluşturabileceği ve bu verileri yönetebileceği basit bir arayüz tasarlamak
Ticari şirketlerde kullanılan basit uygulamalardan esinlenildi
Sistemde her satıcı tüm ürünleri görebilir ancak güvenlik ve gizlilik gereği sadece kendi oluşturduğu siparişlerin detaylarına erişebilir
htmlspeacialchars for XSS(Js) 

# Technology
Php and MySQL(via WampServer-phpmyadmin)
Bootstrap for responsive design, html-css and js(fetch API, searchingn order)

# Database tables
users
products
orders
items - i used this for normalization
